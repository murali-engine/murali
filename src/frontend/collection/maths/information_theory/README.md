# Information Theory

Responsibility: entropy, surprise, cross-entropy, KL divergence, calibration, coding intuition,
compression, and uncertainty in predictions.

Functional anchors today:

- `NextTokenDistribution`, `NextTokenCandidate`, and `NextTokenSampling`
- `AttentionMatrix`
- `TensorSnapshot`, `TensorSelector`, and `TensorView`
- equations, tables, and function graphs

Add here when a component explains uncertainty or information quantities, not just any probability
chart.

Do not put general probability distributions here unless the information-theoretic quantity is the
main object being taught.
