# Probability

Responsibility: random variables, distributions, sampling, conditional probability, Bayes rule,
stochastic processes, and uncertainty before it becomes an information-theory quantity.

Functional anchors today:

- `NextTokenDistribution`, `NextTokenCandidate`, and `NextTokenSampling`
- `TensorSnapshot`, `TensorSelector`, and `TensorView`
- `FunctionGraph`, `ScatterPlot`, and tables

Add here when the component explains probability structure or sampling behavior.

Do not put statistics-specific estimation, summaries, intervals, or model-evaluation views here;
those belong in `statistics`.
