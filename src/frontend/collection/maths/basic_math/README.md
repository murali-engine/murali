# Basic Math

Responsibility: foundational mathematical teaching views for arithmetic, algebra, equations,
matrices, number planes, and function sketches.

Functional anchors today:

- `EquationPart`, equation layouts, and vector equation helpers
- `Matrix`, `MatrixCell`, and `MatrixCellLayout`
- `Label`, `Latex`, `Typst`, `Table`, `Axes`, `NumberPlane`, and `FunctionGraph`

Add here when a component helps explain general math ideas before a more specialized domain such as
linear algebra, calculus, probability, or statistics is needed.

Do not put one-off derivation scenes here. Keep scene-specific equation choreography in examples or
production scene code until it becomes reusable.
