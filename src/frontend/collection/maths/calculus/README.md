# Calculus

Responsibility: visual components for change, accumulation, limits, derivatives, integrals,
gradients, vector fields, curves, and surfaces.

Functional anchors today:

- `FunctionGraph`
- `ParametricCurve` and `ParametricCurve3D`
- `ParametricSurface`
- `VectorField` and `StreamLines`
- `Axes`, `Axes3D`, and `TracedPath`

Add here when a component teaches continuous change or geometric calculus across multiple lessons.

Do not put generic plotting utilities here unless the teaching intent is calculus-specific; generic
plots should remain in `graph` and be re-exported here only as anchors.
