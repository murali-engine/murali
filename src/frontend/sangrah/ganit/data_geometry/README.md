# Data Geometry

Responsibility: embeddings, projections, clusters, manifolds, distances, high-dimensional slices,
and geometric interpretations of data or model state.

Functional anchors today:

- `ScatterPlot`
- `ParametricCurve3D` and `ParametricSurface`
- `TensorSnapshot`, `TensorSelector`, and `TensorView`
- experimental basis, span, and projection helpers when `experimental` is enabled

Add here when a component helps explain data as geometry rather than as raw charts or tables.

Do not put ordinary statistical plots here unless the point is geometric structure such as
projection, neighborhood, distance, or manifold intuition.
