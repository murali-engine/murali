# Statistics

Responsibility: summaries, normalization, estimation, regression, residuals, uncertainty intervals,
correlation, evaluation metrics, and data-to-model reasoning.

Functional anchors today:

- `NormalizationView` and `NormalizationStats`
- `DecisionBoundaryPlot`
- `TensorSample`, tensor snapshots, and tensor views
- `FunctionGraph`, `ScatterPlot`, and tables

Add here when a component explains data summaries, estimation, evaluation, or statistical
relationships.

Do not put pure probability mechanics here unless observed data, estimation, or summary behavior is
central.
