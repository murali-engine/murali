# Optimization

Responsibility: loss landscapes, gradients, descent steps, constraints, learning rates, momentum,
schedulers, optimizer state, and iterative improvement.

Functional anchors today:

- `FunctionGraph`
- `ParametricSurface`
- `VectorField` and `StreamLines`
- `TracedPath`
- tensor snapshots and tensor views
- experimental `ProjectionShadow` when `experimental` is enabled

Add here when a component explains how a quantity is minimized, maximized, constrained, or updated.

Do not put generic animation paths here unless they represent optimization state or an optimizer
trajectory.
