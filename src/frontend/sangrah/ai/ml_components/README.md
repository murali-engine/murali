# ML Components

Responsibility: classical machine-learning concepts such as datasets, features, classifiers,
decision regions, losses, embeddings, metrics, and training/evaluation views.

Functional anchors today:

- `DecisionBoundaryPlot`
- `SignalFlow`
- tensor snapshots, tensor views, tensor slices, and tensor operations
- `TokenSequence`, `ScatterPlot`, and tables

Add here when a component is ML-specific but not necessarily deep-learning-specific.

Do not put transformer-only, LLM-only, or agent-workflow views here; use `ai::transformers_llms` or
`ai::systems_agentic_ai` for those.
